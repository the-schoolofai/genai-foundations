**15.** `invoke` sends one request and waits for the whole reply. `batch` sends several independent requests in parallel and returns replies in the same order. `stream` sends one request and yields the reply in chunks as it is generated.

**16.** (1) The system message comes first, once. (2) Add the user's message before calling the model. (3) Append the reply **message**, not `reply.text`. (4) If the call fails, remove the unanswered question (or, with tools, everything from that turn).

**17.** One question can produce: the user message, an AI message requesting tools, one `ToolMessage` per tool, and the final AI answer, possibly over several rounds. A single `history.pop()` would remove only the last of these. Record `turn_start = len(history)` before the turn and use `del history[turn_start:]` on failure.

**18.** Any two: part of the answer is already on the screen, so a retry would print a second, different answer after the first half; a retry hides the problem from the user; if the user pressed Ctrl+C on purpose, retrying would ignore their choice; a retried stream could repeat tool calls.

### Part C

**C1.** `history.append(reply.text)` adds a plain string, which LangChain treats as a **user** message, so the model thinks the user said its replies. Use `history.append(reply)`.

**C2.** Without a provider prefix, LangChain guesses the provider, and a bare `gemini-...` name currently maps to `google_vertexai` (Google Cloud), which needs Google Cloud credentials, not an AI Studio API key. Use `MODEL_NAME=google_genai:gemini-3.5-flash-lite`. (It may "work" on a machine that happens to have Google Cloud credentials set up.)

**C3.** A cut-off stream can end **without an exception**, so `history.append(full)` saves a half reply. Also, an empty stream would append `None`. Check for a finish reason before saving, and convert the chunk:

```python
if full is not None and full.text and finished(full):
    history.append(message_chunk_to_message(full))
else:
    history.pop()
```

**C4.** (1) No step limit: `while True` can run forever if the model keeps requesting tools. (2) An unknown tool name raises `KeyError`. (3) A tool that raises an exception crashes the app; errors should be returned as a `ToolMessage` with `status="error"`. (Also: no handling for a failed model call.)

**C5.** `answer()` may already have appended an AI tool request and tool results before failing. `history.pop()` removes only the **last** message, leaving the question and partial tool messages behind. Use `turn_start = len(history)` before the turn and `del history[turn_start:]` in the `except`.

**C6.** With tools, a turn is not always two messages. Counting messages from the end can cut a turn in the middle, so the window may start with a `tool` message or an AI tool request, which providers reject or misread. Slice by **user-message positions** instead:

```python
user_positions = [i for i, m in enumerate(history) if is_user(m)]
start = user_positions[-MAX_TURNS] if len(user_positions) > MAX_TURNS else 1
return history[:1] + history[start:]
```

**C7.** Use `include_raw=True`, check `parsing_error`, and fall back if it is set. Also wrap the call in `try` / `except` for connection errors:

```python
result = llm.with_structured_output(ChatSummary, include_raw=True).invoke(conversation)
if result["parsing_error"] is not None:
    print("Sorry, I couldn't create a summary this time.")
else:
    print(result["parsed"].customer_name)
```

**C8.** It prints the full secret key, which can end up in screenshots, logs, or shared terminal output. Print a masked version, for example the first 4 and last 2 characters, or just "set" / "not set" (as in `check_setup.py` from Lesson 4.1).

## Reference Solution for Part D

Try the challenge before reading this. This solution was tested in the `cue-chat` project (see the table after the code).

`cue_final.py` uses `config.py` (4.1), `tools.py` (4.5), and `schemas.py` (4.6):

```python
"""Cue Chat: the complete Module 4 app (reference solution)."""

from langchain.messages import AIMessage, ToolMessage
from langchain_core.messages import message_chunk_to_message
from langchain_core.messages.utils import convert_to_messages

from config import get_llm
from schemas import ChatSummary
from tools import TOOLS

SYSTEM_PROMPT = "You are Cue, a helpful AI assistant. Use tools when they help. Keep answers short."
MAX_TURNS = 10   # user turns sent to the model
MAX_STEPS = 5    # model calls per turn (tool rounds)
EXIT_WORDS = ("exit", "quit", "bye", "/exit")
HELP = "Commands: /help  /history  /reset  /summary  /exit   (Ctrl+C while Cue is typing stops the reply)"

tools_by_name = {t.name: t for t in TOOLS}
llm = get_llm()
llm_with_tools = llm.bind_tools(TOOLS)
summarizer = get_llm(temperature=0).with_structured_output(ChatSummary, include_raw=True)


class IncompleteReply(Exception):
    """The stream ended without a finish reason."""


def new_history() -> list:
    return [{"role": "system", "content": SYSTEM_PROMPT}]


def is_user(message) -> bool:
    return message["role"] == "user" if isinstance(message, dict) else message.type == "human"


def recent(history: list) -> list:
    """System message + the last MAX_TURNS user turns, always starting at a user message."""
    user_positions = [i for i, m in enumerate(history) if is_user(m)]
    start = user_positions[-MAX_TURNS] if len(user_positions) > MAX_TURNS else 1
    return history[:1] + history[start:]


def finished(message) -> bool:
    metadata = message.response_metadata
    return bool(metadata.get("finish_reason") or metadata.get("done_reason") or metadata.get("stop_reason"))


def run_tool(call: dict) -> ToolMessage:
    tool = tools_by_name.get(call["name"])
    if tool is None:
        return ToolMessage(f"Error: unknown tool '{call['name']}'.", tool_call_id=call["id"], status="error")
    try:
        return tool.invoke(call)
    except Exception as error:
        return ToolMessage(f"Error: {error}", tool_call_id=call["id"], status="error")


def stream_once(messages: list):
    """Stream one model reply, printing text as it arrives. Return a complete AIMessage."""
    full = None
    for chunk in llm_with_tools.stream(messages):
        print(chunk.text, end="", flush=True)
        full = chunk if full is None else full + chunk
    if full is None or not finished(full):
        raise IncompleteReply()
    return message_chunk_to_message(full)


def answer(history: list) -> None:
    """Run streaming + tool rounds. Appends every new message to history."""
    print("Cue: ", end="", flush=True)
    for _ in range(MAX_STEPS):
        reply = stream_once(recent(history))
        history.append(reply)
        if not reply.tool_calls:
            print()
            return
        for call in reply.tool_calls:
            print(f"[using tool: {call['name']}] ", end="", flush=True)
            history.append(run_tool(call))
    apology = "Sorry, I could not finish that within the step limit."
    history.append(AIMessage(apology))  # end the turn with an AI message, so history stays well-formed
    print(f"\nCue: {apology}")


def show(history: list) -> None:
    for message in convert_to_messages(history):
        calls = ", ".join(f"asks for {c['name']}" for c in getattr(message, "tool_calls", []))
        print(f"  [{message.type}] {(message.text or calls)[:70]}")


def summarize(history: list) -> None:
    conversation = [m for m in convert_to_messages(history) if m.type in ("human", "ai") and m.text]
    if not conversation:
        print("Cue: Nothing to summarize yet.")
        return
    result = summarizer.invoke([{"role": "system", "content": "Summarize this support conversation."}, *conversation])
    if result["parsing_error"] is not None:
        print("Cue: Sorry, I couldn't create a summary this time.")
        return
    summary = result["parsed"]
    with open("chat_summary.json", "w", encoding="utf-8") as file:
        file.write(summary.model_dump_json(indent=2))
    print(f"  Customer: {summary.customer_name or 'unknown'} | Topics: {', '.join(summary.topics)} | "
          f"Needs human: {'yes' if summary.needs_human else 'no'}  (saved to chat_summary.json)")


def main() -> None:
    history = new_history()
    print(f"Welcome to Cue Chat! {HELP}")

    while True:
        try:
            question = input("You: ").strip()
        except (KeyboardInterrupt, EOFError):
            print("\nGoodbye!")
            break

        if not question:
            continue
        command = question.lower()
        if command in EXIT_WORDS:
            print("Goodbye!")
            break
        if command == "/help":
            print(HELP)
            continue
        if command == "/history":
            show(history)
            continue
        if command == "/reset":
            history = new_history()
            print("Cue: Memory cleared. Let's start again.")
            continue
        if command == "/summary":
            try:
                summarize(history)
            except Exception as error:
                print(f"Cue: Sorry, the summary failed ({type(error).__name__}).")
            continue

        turn_start = len(history)
        history.append({"role": "user", "content": question})
        try:
            answer(history)
        except KeyboardInterrupt:
            del history[turn_start:]
            print("\n[stopped]")
        except IncompleteReply:
            del history[turn_start:]
            print("\n[connection lost: the reply was incomplete. Please try again.]")
        except Exception as error:
            del history[turn_start:]
            print(f"\n[error: {type(error).__name__}. Please try again.]")


if __name__ == "__main__":
    main()
```
