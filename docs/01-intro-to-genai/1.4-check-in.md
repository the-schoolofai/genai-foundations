### Part C

**C1.** `stream=True` is missing, so the call returns one complete response instead of chunks. Add `stream=True`, and guard against empty chunks:

```python
stream = client.chat.completions.create(
    model=model,
    messages=[{"role": "user", "content": "Explain tokens in 2 lines."}],
    stream=True,
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()
```

**C2.** The API key is hard-coded. Anyone who sees the code (or the GitHub repository) can use the key and charge your account. Move it to `.env`, list `.env` in `.gitignore`, and read it with `load_dotenv()` and `os.getenv("OPENAI_API_KEY")`, or use `get_client()` from `llm.py`. If a real key was ever committed, revoke it and create a new one.

**C3.** `ticket.priority` is a `str`, and it can only be `"low"`, `"medium"`, or `"high"`. Pydantic rejects any other value.

**C4.** Change `PROVIDER=ollama` to `PROVIDER=gemini` in `.env` (and make sure `GEMINI_API_KEY` is set). No Python code changes.
